# Лог: jumper TX PB13→DD4 — CAN2 ОЖИЛ ✅

Дата: **2026-08-23**  
Предыдущий: [2026-08-23_before_tx_jumper_poweroff.md](2026-08-23_before_tx_jumper_poweroff.md)

---

## Что сделали

Jumper **PB13 → DD4 pin 1 (TX)** — обход битой дорожки.

---

## Результат

- **При включении** правая лапа **подвигалась** (пользователь подтвердила)
- **Причина была:** обрыв/плохая **дорожка TX**, не мёртвый MAX3051
- **DD4 менять не нужно** (пока jumper держится)

### probe (стабильно)
```
leg0 CAN1: abad=0.115 hip=-0.283 knee=0.126  ✅
leg1 CAN2: abad=-0.020 hip=0.038  knee=-0.107  ✅
```

### SPI
- ~0.3 ms на кадр, **0 bad frames** — задержки SPI нет
- CE1 spidev0.1 по-прежнему all_zero (вторая STM)

### wiggle в тесте
span=0 на обеих ногах — робот **лежит**, суставы упираются. Не показатель.

---

## Про «задержку в ПО» и движение при boot

- `robot.service` **enabled** — при включении запускается homing, лапы **двигаются**
- Это **нормально**, не баг CAN2
- Для ручных тестов: `sudo systemctl stop robot.service`
- Для работы: `sudo systemctl start robot.service`

---

## Рекомендации

1. **Jumper оставить** — позже можно восстановить дорожку
2. Закрепить провод (капton / термоклей), чтобы не оторвался
3. Запустить robot.service и проверить обе передние ноги стоя/в безопасном положении
